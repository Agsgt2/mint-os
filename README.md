## How do versions work???
This is a category about how the version name works.
### RELEASES
Here is an example of an normal version name and their parts:
```
EDIT
 |
 v
v1.1856
    ^
    |
TIME WHEN RELEASE WAS DONE CODING
```
### BETA RELEASES
Here is an example of an beta version name and their parts:
```
EDIT   SNAPSHOT NUMBER
 |      |
 v      v
v2.2001.2
    ^
    |
TIME WHEN RELEASE WAS DONE CODING
```
